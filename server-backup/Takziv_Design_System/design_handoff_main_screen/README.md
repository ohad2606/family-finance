# Handoff: מסך ראשי חדש — "פנוי להוצאה" (Takziv main screen redesign)

## Overview
עיצוב מחדש למסך הבית של אפליקציית **תקציב** (family-finance). המטרה: מסך נקי וזורם שעונה במבט
אחד-שתיים על השאלה *"כמה אני יכול להוציא עכשיו?"* ומאפשר הוספת הוצאה מהירה. המסך מחליף את
`DashboardPage.jsx` הנוכחי (שהיה עמוס: שווי נקי, ציון בריאות, גרף תזרים, דונאט, יעדי חיסכון, הלוואות).

הכיוון שנבחר (מבין 3) הוא **"חודשי רגוע"**: מספר חודשי גדול ושקט בראש, עם מסגור יומי, ותקציבי
קטגוריות כפסי התקדמות.

## About the Design Files
הקבצים בחבילה הם **רפרנס עיצובי שנבנה ב־HTML/React** — פרוטוטיפ שמראה את המראה וההתנהגות הרצויים,
**לא קוד פרודקשן להעתקה ישירה**. המשימה היא **לשחזר את העיצוב בתוך ה־codebase הקיים** של
`family-finance` (React 19 + Vite, עם style objects inline — בדיוק כמו שאר העמודים בפרויקט),
תוך שימוש בדפוסים ובמוסכמות הקיימים שם (React Router, TanStack Query, פונקציות `getX` מ־`api/finance.js`).

הפרוטוטיפ משתמש בקומפוננטות של design-system נפרד; בקוד האמיתי אין צורך בהן — ממשו עם style objects
inline כמו ב־`DashboardPage.jsx` המקורי.

## Fidelity
**High-fidelity (hifi).** צבעים, טיפוגרפיה, מרווחים ורדיוסים סופיים ומדויקים. יש לשחזר פיקסל-פרפקט
עם הדפוסים הקיימים בקוד. כל הערכים המדויקים מופיעים בהמשך.

## Screen: מסך ראשי (Home / Dashboard)

**Purpose:** המשתמש רואה במבט אחד כמה פנוי לו להוציא (היום ועד סוף החודש), מצב התקציבים לפי קטגוריה,
סיכום החודש, והתנועות האחרונות — ומוסיף הוצאה בלחיצה אחת.

**Layout (top → bottom), עמודה מובייל ברוחב מלא, `direction: rtl`:**
1. **Header** — שורת ברכה ("ערב טוב," + שם בגופן Heebo 900) משמאל, לוגו תקציב מימין. padding `1rem 1.15rem 0.5rem`.
2. **Hero "פנוי להוצאה"** — כרטיס כהה (`--ink`), radius 20, padding `1.3rem`. label, מספר ענק (Heebo 900, 2.5rem, tabular-nums), כיתוב משנה, ושני אריחים שקופים (`rgba(255,255,255,0.07)`): "בערך ליום ≈ ₪218" ו"לסוף החודש · 20 ימים".
3. **סיכום חודשי** — שני כרטיסים שווים (`--card`, radius 12): "הכנסות החודש" (ירוק) ו"הוצאות החודש" (טרקוטה).
4. **התראת חריגה** — באנר ענבר (`--alert-bg` + border `--alert-border`, טקסט `--alert-text`), radius 12. מופיע רק אם יש קטגוריה בחריגה.
5. **תקציב לפי קטגוריה** — כרטיס `--card` radius 16. כותרת + קישור "הכל". רשימת קטגוריות, לכל אחת: שם+אמוג'י, "נשאר ₪X" (או "חריגה ₪X" באדום), פס התקדמות (גובה 7px), ושורת `₪spent / ₪planned`.
6. **תנועות אחרונות** — כרטיס `--card` radius 16. כותרת + "הכל". שורות עם עיגול-אמוג'י (32px), תיאור+תאריך, וסכום צבוע (+ ירוק / − טרקוטה).
7. **FAB** — כפתור עגול 56px, `--brass`, צל `--shadow-cta`, פינה תחתונה־התחלה (`inset-inline-end: 20px`). פותח את גיליון "הוסף הוצאה".

הרווח האנכי בין הסקשנים: `0.85rem`. padding צדדי: `1.15rem`.

### Add-expense bottom sheet
גיליון שעולה מלמטה (overlay עם scrim `rgba(27,42,39,0.40)`), `border-radius: 22px 22px 0 0`, ידית
אחיזה אפורה למעלה. תוכן: כותרת "הוסף הוצאה", מתג הוצאה/הכנסה (הפעיל נצבע בצבע המתאים), שדה סכום ענק
(Heebo 900, מרכז, קו תחתון), select קטגוריה, select חשבון, שדה תיאור, וכפתור "שמור" מלא־רוחב
(צבעו = expense/income לפי המתג). אנימציות: `tz-fade` 0.2s ל־overlay, `tz-rise` 0.28s לגיליון.

## Interactions & Behavior
- **FAB / "+ הוסף"** → פותח את גיליון הוספת ההוצאה. שמירה מוסיפה תנועה לראש "תנועות אחרונות" (אופטימי) ומרעננת סיכומים.
- מתג הוצאה/הכנסה משנה את רשימת הקטגוריות בהתאם ל־`kind` ואת צבע כפתור השמירה.
- "הכל" בכל סקשן → ניווט לעמוד המלא (קטגוריות / תנועות).
- התראת החריגה → ניווט לעמוד התקציב.
- פסי התקדמות מונפשים ברוחב: `transition: width 0.4s ease`.
- אין אנימציות כניסה מורכבות; הסגנון רגוע ומיידי.

## ★ דרישות שהמשתמש שולט בהן (חשוב — לבנות כהגדרות)
שני דברים הם **תלויי-העדפת-משתמש** ויש לחשוף אותם בהגדרות (ולא לקבע):
1. **מה נכנס לחישוב "פנוי להוצאה".** ברירת המחדל: סכום היתרות של החשבונות הנזילים שנבחרו, פחות הוראות
   הקבע / התשלומים הקבועים שעדיין צפויים להיחויב החודש. המשתמש בוחר **אילו חשבונות** נספרים נזילים
   ו**אילו חיובים/קטגוריות** מנוכים מהחישוב. הנוסחה: `available = Σ(selected liquid balances) − Σ(pending fixed charges this month)`. גם `perDay = available / daysLeftInMonth`.
2. **אילו קטגוריות מופיעות במסך הראשי.** המשתמש בוחר/מצמיד קטגוריות (ברירת מחדל: 3 המובילות לפי הוצאה
   החודש); השאר נגישות דרך "הכל". יש לשמור את הבחירה (למשל בהעדפות המשק בית / localStorage / טבלת settings).

מומלץ: שדה `include_in_available` בוליאני על חשבון/קטגוריה, ושדה `pinned_to_home` / `home_order` על קטגוריה.

## State Management
- שאילתות קיימות (TanStack Query): `getAccounts`, `getBudget(month)`, `getUpcomingRecurring`, `getTransactions`, `getDashboardSummary`.
- חדש: גזירת `available` ו־`perDay` מהנתונים לפי העדפות המשתמש (ראה למעלה). `daysLeftInMonth` מחושב מהתאריך.
- מצב מקומי: `showSheet` (בוליאני), שדות טופס ההוספה (`kind`, `amount`, `category_id`, `account_id`, `description`).

## Design Tokens (ערכים מדויקים)
תואם ל־`const C` הקיים ב־`DashboardPage.jsx`:
```
--paper   #E9EBE4   (רקע אפליקציה)        --income  #2F6B4F  (הכנסה / "נשאר" תקין)
--card    #F7F8F4   (כרטיס)               --expense #B0573C  (הוצאה / חריגה)
--ink     #1B2A27   (כרטיס כהה / טקסט)     --brass   #C9A23F  (פעולה / FAB / "הכל")
--muted   #6B746E   (טקסט משני)            --line    #D5D8CF  (גבולות / מפרידים)
```
על כרטיס כהה: tile fill `rgba(255,255,255,0.07)`, sub-text `rgba(255,255,255,0.6)`, faint `rgba(255,255,255,0.35)`.
התראה: bg `#FEF3C7`, border `#FCD34D`, text `#92400E`.
פס תקציב — צבע לפי מצב: תקין `--income`, מעל 85% `--brass`, חריגה `--expense`.

**Typography:** body/UI = **Assistant** (400/600/700); display + כל מספר כספי = **Heebo** (700/900),
תמיד `font-variant-numeric: tabular-nums`. כסף: `Intl.NumberFormat('he-IL',{style:'currency',currency:'ILS',maximumFractionDigits:0})`.

**Radii:** sm 8 · md 12 · lg 16 · xl 20 · sheet-top 22 · FAB 50%.  **Spacing:** סקשנים 0.85rem, צד 1.15rem.
**Shadows:** CTA/FAB `0 4px 16px rgba(201,162,63,0.35)`; שאר הכרטיסים — ללא צל.
