מסך ראשי — שלוש גישות

הגיבור: "פנוי להוצאה" (יתרה אחרי הוראות קבע ותשלומים קבועים), במסגור יומי + חודשי, עם תקציבי קטגוריות. כל מסך אינטראקטיבי — לחצו על ה־+ להוספת הוצאה.

גישה A
חודשי רגוע

מספר חודשי גדול ושקט בראש, עם "ליום" ו"ימים לסוף החודש". תקציבי הקטגוריות כפסים מתחת.

גישה B
חוגה יומית

"כמה יש לי להיום" כחוגה מרכזית, והחודשי כשורה משנית. מתאים למי שמנהל יום-יום.

גישה C
תקציבים במרכז

באנר פנוי דק, והקטגוריות הן הגיבור — רשת אריחים עם "נשאר" לכל קטגוריה במבט אחד.
